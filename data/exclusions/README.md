# Local OSM exclusion context

Derived from the previously authorized, bounded OpenStreetMap Overpass snapshots stored on this machine (retrieved 2026-10-22). Each file contains only relevant buildings/residential/private-access features, plus source snapshot metadata and the original query coverage polygon.

Attribution: © OpenStreetMap contributors. Source licence and attribution requirements: https://www.openstreetmap.org/copyright (ODbL).

These are unverified map features, not cadastral parcels or confirmed property rights. A broad residential polygon can contain public vegetation. Coverage is limited to the earlier supplied study polygons; analyse_scene reports source-valid area outside that coverage. Missing geometry/tags cannot establish absence of houses or public access. Do not create property boundaries from point features.
